# Prototype traceability register

Each prototype requirement maps to the component that enforces it, the workflow step it governs, its safeguard, and the tests that check it. Requirement IDs are prototype-local and are all classified **Prototype requirement** unless noted. "Evidence" means the JUnit report and run record in `evidence/runs/<timestamp>/` produced by `scripts/run_evaluation.py`. A requirement counts as verified only when a reviewed run record shows its tests passing.

## Workflow step key

- **A1** load or submit input · **A2** employee review (submission) · **A3** Role Execution Agent REQ assessment, tagging, and draft creation · **A2T** TTO lead review (roster workflow; follows A3) · **A4** human PMO decision · **A5** publication
- **B1** query validation · **B2** gateway retrieval · **B3** Expertise Agent explanation and validation · **B4** escalation routing · **B5** response · **B6** reviewer acknowledgement

## Not yet verified or out of scope

- Live Claude mode was last recorded in `EVAL-20261031T203347Z`, before PR-30 and `role_execution_v3`; the current agent version has no recorded live run. Mock-mode results measure the governance pipeline, not language-model quality.
- Claude's roster judgments have no answer key and no completed human sample review (PR-32 provides the sheet; runs before PR-32 did not save statement-level results).
- The Delivery restricted execution path (Vol 07 §3.6.4) is implemented as routing only: gaps escalate to the Delivery owner. In-Delivery matching and export of approved results are not built.
- Authentication is simulated by fixture lookup; there is no real identity provider.
- The course rubric has not been mapped (see the Build Guide's rubric checklist).
- Career pathways, Scala Lucida (FC-01, Increment 5; formerly LITE-BRITE), is out of scope and has no requirement rows. The name and the pronunciations for StrataCaster and Scala Lucida are recorded in CR-SC-2026-006 (Volumes 01, 08 and 00; accepted 2026-11-14).
- Public release of this prototype (synthetic data, code and recorded evidence, for academic review) is permitted by CR-SC-2026-007 (Vol 01 §1.2, accepted 2026-11-14); `data/manifest.json` records the permitted use. Real or production data is never published.
